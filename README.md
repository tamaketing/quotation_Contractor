# ระบบเอกสารรับเหมา — Quotation / Invoice / Receipt / Delivery Letter

เครื่องมือทำเอกสารชุดนี้สำหรับผู้รับเหมาก่อสร้าง ใช้ผ่านเว็บเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรม
ข้อมูลทั้งหมดถูกเก็บไว้ในเครื่องของผู้ใช้เอง ไม่ถูกส่งขึ้นเซิร์ฟเวอร์ใดๆ

> วิธี deploy ขึ้น Cloudflare Pages (HTTPS ฟรี) ดูขั้นตอนใน [`DEPLOY.md`](DEPLOY.md)

| เอกสาร | ไฟล์ | ความสามารถ |
|---|---|---|
| ใบเสนอราคา | [`quotation.html`](quotation.html) | แบ่งหมวดหมู่ · ค่าวัสดุ/ค่าแรง · จำนวนเงินเป็นตัวหนังสือไทย · เลขที่นับต่อเอง |
| ใบแจ้งหนี้ | [`invoice.html`](invoice.html) | VAT · หักประกัน · เงินล่วงหน้า · ภาษี ณ ที่จ่าย · ยอดสุทธิ · เขียนไฟล์ลงโฟลเดอร์จริง |
| ใบเสร็จรับเงิน / ใบกำกับภาษี | [`receipt.html`](receipt.html) | นำเข้าจากใบแจ้งหนี้ · รายละเอียดการรับชำระ · คำนวณยอดสุทธิและจำนวนเงินเป็นตัวหนังสือ · พิมพ์ A4 |
| หนังสือส่งมอบงานจ้าง | [`delivery-letter.html`](delivery-letter.html) | นำเข้าข้อมูลจากใบแจ้งหนี้ · คำนวณยอดและตัวเลขไทยให้อัตโนมัติ |

## เริ่มใช้งาน

เปิด [`index.html`](index.html) ในเบราว์เซอร์ (Chrome หรือ Edge แนะนำ) แล้วกดรหัสผ่าน

### เลขที่เอกสาร

| เอกสาร | รูปแบบ | ตัวเลขวิ่ง |
|---|---|---|
| ใบเสนอราคา | `PCC-2569-001` | ต่อตามปี พ.ศ. |
| ใบแจ้งหนี้ | `INV-2569-001` | ต่อตามปี พ.ศ. |
| ใบเสร็จรับเงิน | `RC-2569-001` | ต่อตามปี พ.ศ. |

- ระบบหาค่าสูงสุดจากเอกสารที่เก็บไว้ และจำเลขที่เคยออกแล้ว จึงไม่นำเลขที่ลบไปกลับมาใช้
- ถ้าแก้เลขที่ด้วยมือแล้วซ้ำกับใบอื่น จะมีกรอบแดงและคำเตือน
- หนังสือส่งมอบงานจ้างยังใช้ **เลขที่ใบแจ้งหนี้ที่อ้างถึง** เป็นตัวอ้างอิง

### 1. ตั้งค่าข้อมูลบริษัท (ทำครั้งเดียว)

กดปุ่ม **⚙ ข้อมูลบริษัท** แล้วกรอก

- ชื่อบริษัท / ชื่อภาษาอังกฤษ
- ที่อยู่
- เลขประจำตัวผู้เสียภาษี
- โทรศัพท์ / อีเมล
- ชื่อผู้เสนอราคาและเบอร์โทร
- อายุใบเสนอราคา, อัตราภาษีมูลค่าเพิ่ม
- ข้อความชำระเงิน / โอนเงิน
- อัปโหลดโลโก้ (ระบบย่อขนาดให้อัตโนมัติ)

ข้อมูลชุดนี้จะถูกใช้กับทุกเอกสารในเครื่องนั้น

> ย้ายเครื่องหรือใช้หลายเครื่อง → กด **ส่งออก (.json)** แล้วนำไปกด **นำเข้า** ที่เครื่องปลายทาง

### 2. สร้างเอกสาร

ทุกหน้าจะมีแผง **📁 … ที่ทำไว้** ด้านบน ใช้จัดการเอกสารได้เลย

| ปุ่ม | ทำอะไร |
|---|---|
| **+ ใบใหม่** | เปิดเอกสารว่าง เลขที่จะนับต่อจากใบล่าสุดให้อัตโนมัติ |
| **ทำซ้ำ** | คัดลอกใบปัจจุบันพร้อมเลขที่ใหม่ |
| **ส่งออกทั้งหมด** | ดาวน์โหลดเป็น ZIP แยกโฟลเดอร์ตามปี |
| **ลบใบนี้** | ลบเอกสารที่เปิดอยู่ |
| ช่องค้นหา | ค้นจากเลขที่ / ชื่อลูกค้า / ชื่อโครงการ |

เอกสารจะบันทึกอัตโนมัติทุกครั้งที่พิมพ์

### 3. บันทึกเป็น PDF

กด **พิมพ์ / PDF** แล้วตั้งค่า

- ขนาดกระดาษ **A4**
- ขอบ **ไม่มี (None)**
- เปิด **พื้นหลังกราฟิก / Background graphics** ไว้ เพื่อให้สีช่องตารางออกมา
- ปลดล็อกหัวกระดาษและท้ายกระดาษในเบราว์เซอร์

หนังสือส่งมอบงานจ้างมีตัวเลือกขนาด 85–105% ด้านบน ถ้ายังไม่พอดีหนึ่งหน้า

## โฟลเดอร์สำรอง (เขียนไฟล์ลงดิสก์อัตโนมัติ)

**มีในทุกหน้า** — กดปุ่ม **📁 โฟลเดอร์สำรอง** ที่แถบล่างของรายการเอกสาร แล้วเลือกโฟลเดอร์
(แนะนำให้เลือกโฟลเดอร์ที่อยู่ใน **OneDrive** หรือ **Google Drive**)

จากนั้นทุกครั้งที่พิมพ์แก้ไข ระบบจะเขียนไฟล์ `.json` ลงโฟลเดอร์นั้นให้เอง โดยแยกโฟลเดอร์ย่อยตามปี พ.ศ.

```
OneDrive/งานรับเหมา/
├─ 2569/
│  ├─ PCC-2569-001_บริษัท สยาม....json
│  ├─ INV-2569-003_บริษัท สยาม....json
│  ├─ RC-2569-001_บริษัท สยาม....json
│  └─ HANDOVER-INV-2569-003_บริษัท สยาม....json
└─ 2570/
```

ชื่อไฟล์ประกอบด้วย **เลขที่เอกสาร_ชื่อลูกค้า** — ถ้ามีการแก้ไขเอกสารเดิมไฟล์เดิมจะถูกเขียนทับ (ไม่กองไฟล์)

> **ข้อจำกัดสำคัญ:** ฟีเจอร์นี้ต้องรันบน `https://` หรือ `localhost` เท่านั้น
> ถ้าเปิดจากไฟล์ในเครื่อง (`file://`) ปุ่มจะแจ้งว่าใช้ไม่ได้ — ให้กด **Export** แทน
>
> นอกจากนี้เบราว์เซอร์จะถามสิทธิ์ใหม่ทุกครั้งที่เปิดหน้าใหม่ กดอนุญาตเมื่อถาม

**ปุ่ม “ส่งออกทั้งหมด”** กดได้ทุกหน้าเช่นกัน — รวบรวมเอกสารทั้งหมดเป็นไฟล์ ZIP เก็บเป็นระยะ

### สำรองข้อมูลอยู่ที่ไหน

เอกสารถูกเก็บไว้ **2 ที่** พร้อมกันเสมอ

| ที่ | ข้อดี | ข้อควรระวัง |
|---|---|---|
| ในเบราว์เซอร์ (localStorage) | เปิดใช้ทันที ไม่ต้องรอ | ล้างข้อมูลเว็บ = หาย · ผูกกับเครื่องและที่อยู่เว็บ |
| โฟลเดอร์สำรองบนเครื่อง | ไม่หาย · เข้าถึงได้จากเครื่องอื่น | ต้องเลือกโฟลเดอร์ก่อน |

**ที่อยู่เว็บสำคัญมาก** — ข้อมูลผูกกับ URL ที่เปิด
เปลี่ยนชื่อ repo หรือที่อยู่เว็บ ข้อมูลเดิมจะไม่ปรากฏ (ไฟล์ในโฟลเดอร์สำรองยังอยู่ครบ)
ควรตั้งชื่อ repo ให้เสร็จก่อนเริ่มใช้งานจริง

## ใบเสร็จรับเงิน / ใบกำกับภาษี

กด **นำเข้าจากใบแจ้งหนี้** แล้วเลือกไฟล์ `.json` ที่ Export มาจาก `invoice.html` ระบบจะนำข้อมูลลูกค้า โครงการ รายการงาน และยอดภาษีมาให้ จากนั้นกรอกวันที่รับชำระ วิธีชำระเงิน และเลขอ้างอิงการโอน/เช็ค แล้วตรวจสอบยอดก่อนพิมพ์

## หนังสือส่งมอบงานจ้าง

กด **นำเข้าจากใบแจ้งหนี้** แล้วเลือกไฟล์ `.json` ที่ Export มาจาก `invoice.html`
ระบบจะดึงข้อมูลต่อไปนี้มาให้อัตโนมัติ

- เลขที่และวันที่ใบแจ้งหนี้, กำหนดชำระ
- ชื่อผู้รับจ้าง
- โครงการ, สถานที่, เลขที่สัญญา
- รายการงานทั้งหมด
- ยอดสุทธิ (หัก VAT · หักประกัน · เงินล่วงหน้า · ภาษี ณ ที่จ่าย)

ข้อความในหนังสือจะถูกประกอบขึ้นใหม่ให้อัตโนมัติ — **ควรตรวจสอบยอดเงินและรายละเอียดอีกครั้งก่อนพิมพ์**

---

## ⚠️ ข้อควรระวัง

- เอกสารทั้งหมดถูกเก็บใน **localStorage ของเบราว์เซอร์ในเครื่องนั้น**
- **ล้างข้อมูลเว็บ = เอกสารหาย** และใช้หมดแบบไม่ระบุตัวตน (Incognito) จะไม่เก็บข้อมูลเลย
- ควรกด **Export** เก็บไฟล์ `.json` ไว้ใน OneDrive / Google Drive เป็นประจำ
- ห้ามใช้งานบนคอมพิวเตอร์สาธารณะหรือเครื่องที่ใช้ร่วมกับคนอื่น ถ้ามีข้อมูลงานจริงอยู่
- รหัสผ่านหน้าแรกเป็นเพียงการป้องกันเบื้องต้นกันการแชร์ลิงก์ต่อ **ไม่ใช่การเข้ารหัสจริง**
  เปลี่ยนรหัสได้ที่ปุ่ม “เปลี่ยนรหัสผ่าน” ในหน้าตั้งค่า

## โครงสร้างไฟล์

```
index.html              หน้าแรก เลือกเครื่องมือ
quotation.html          ใบเสนอราคา
invoice.html            ใบแจ้งหนี้
receipt.html            ใบเสร็จรับเงิน / ใบกำกับภาษี
delivery-letter.html    หนังสือส่งมอบงานจ้าง
assets/
  app.css               สไตล์กลาง (ปฏิทิน, หน้าต่างตั้งค่า, แผงจัดการเอกสาร)
  thai.js               ตัวเลขไทย · จำนวนเงินเป็นตัวหนังสือ · ปฏิทิน พ.ศ.
  profile.js            ข้อมูลบริษัท + หน้าต่างตั้งค่า
  docs.js               แผงจัดการเอกสาร (เก็บแยกเป็นรายใบ)
  docnum.js             เลขที่เอกสารกลาง (ปี พ.ศ. + กันเลขซ้ำ/เลขย้อนกลับ)
  archive.js            เขียนไฟล์ .json ลงโฟลเดอร์จริง (File System Access API)
  gate.js               หน้าล็อกรหัสผ่าน
```

รหัสผ่านเริ่มต้นกำหนดไว้ที่ [`assets/gate.js`](assets/gate.js) ค่า `DEFAULT_PASSWORD`
แก้แล้ว commit ขึ้นใหม่ก็จะเปลี่ยนรหัสใหม่ทั้งระบบ (ผู้ใช้ที่เคยเปลี่ยนเองจะไม่ถูกเปลี่ยน)
