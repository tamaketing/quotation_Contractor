ใบเสนอราคา · ใบแจ้งหนี้ · ใบเสร็จรับเงิน · หนังสือส่งมอบงานจ้าง

📝

ใบเสนอราคา

Quotation — แบ่งหมวดหมู่ คิดค่าวัสดุ/ค่าแรง พร้อมจำนวนเงินเป็นตัวหนังสือ

  • เลขที่เอกสารนับต่อเอง
  • เก็บได้หลายใบ ค้นหา/ทำซ้ำ/ลบ
  • ส่งออกทั้งหมดเป็น ZIP แยกตามปี
🧾

ใบแจ้งหนี้

Invoice — VAT · หักประกัน · เงินล่วงหน้า · ภาษี ณ ที่จ่าย · ยอดสุทธิ

  • เก็บได้หลายใบ ค้นหา/ทำซ้ำ/ลบ
  • เขียนไฟล์ลงโฟลเดอร์จริงแยกตามปี (OneDrive/Google Drive)
  • ส่งออกทั้งหมดเป็น ZIP
✅

ใบเสร็จรับเงิน / ใบกำกับภาษี

Receipt / Tax Invoice — รับชำระเงิน พร้อมภาษีและยอดเงินเป็นตัวหนังสือ

  • นำเข้าข้อมูลจากใบแจ้งหนี้ได้
  • บันทึกวิธีชำระ ธนาคาร เช็ค และเลขอ้างอิง
  • เก็บได้หลายใบ พิมพ์ A4 พร้อมช่องลงนาม
📄

หนังสือส่งมอบงานจ้าง

Delivery & Payment Request Letter — ขอเบิกจ่ายเงินงวด

  • นำเข้าข้อมูลจากไฟล์ใบแจ้งหนี้ได้
  • ยอดเงินและตัวเลขไทยคำนวณให้อัตโนมัติ
  • เก็บได้หลายฉบับ

⚙ ข้อมูลบริษัท

กดปุ่ม “⚙ ข้อมูลบริษัท” ด้านบน หรือในหน้าเอกสารใดก็ได้ (ใบเสนอราคา / ใบแจ้งหนี้ / ใบเสร็จรับเงิน / หนังสือส่งมอบงาน)
กรอกชื่อบริษัท ที่อยู่ เลขประจำตัวผู้เสียภาษี สาขา โทร อีเมล ชื่อผู้เสนอราคา บัญชีธนาคาร และอัปโหลดโลโก้ — ตั้งค่าที่เดียว ใช้ได้กับทุกเอกสารอัตโนมัติ
ย้ายเครื่องหรือใช้หลายเครื่อง → กด “ส่งออก (.json)” แล้วนำไปกด “นำเข้า” ที่เครื่องปลายทาง

👥 ทะเบียนลูกค้า

ระบบจะจำ ชื่อลูกค้า / ที่อยู่ / เลขผู้เสียภาษี / ผู้ติดต่อ จากใบเสนอราคาและใบแจ้งหนี้ให้อัตโนมัติ
ครั้งต่อไปเปิดใบใหม่ กด “👥 เลือกลูกค้าเก่า” แล้วเลือกรายชื่อได้เลย — ไม่ต้องพิมพ์ซ้ำ

🔐 บัญชีและการเข้าสู่ระบบ

บัญชีนี้ใช้สำหรับเข้าสู่ระบบจากทุกเครื่อง — ข้อมูลบริษัทและเอกสารเก็บบน Cloud (D1)
เปลี่ยนรหัสผ่านได้ที่ปุ่ม “⚙ ข้อมูลบริษัท” → เปลี่ยนรหัสผ่าน หรือออกจากระบบด้วยปุ่มมุมขวาบน

⚠️ ข้อควรระวังเรื่องข้อมูล

  • เอกสารและข้อมูลบริษัทถูกเก็บไว้บน Cloud (Cloudflare D1) — เปิดบัญชีเดิมจากเครื่องไหนก็เห็นข้อมูลเดียวกัน
  • ในเครื่องนี้เก็บเพียง token การเข้าสู่ระบบ และแคชข้อมูลบริษัท — ถ้าล้างข้อมูลเบราว์เซอร์จะต้องล็อกอินใหม่ แต่เอกสารไม่หาย
  • ข้อมูลบางช่อง (ชื่อผู้เสนอราคา / อายุใบเสนอราคา / อัตรา VAT) ยังเก็บเฉพาะเครื่องนี้
  • ควร Export ไฟล์ .json เก็บไว้เป็นสำเนาเป็นระยะ และห้ามใช้เครื่องสาธารณะโดยไม่กด “ออกจากระบบ”

🖨️ บันทึกเป็น PDF

กดปุ่ม “พิมพ์ / PDF” แล้วเลือก เครื่องพิมพ์ → บันทึกเป็น PDF (หรือเลือกปลายทางเป็น “Save as PDF”)
ตั้งขอบกระดาษเป็น A4 · ไม่มีหัวกระดาษ/ท้ายกระดาษ · ขอบ 0 · เปิด “พื้นหลังกราฟิก” ไว้เพื่อให้สีช่องตารางออกมา

ไปที่ใบเสนอราคา → ไปที่ใบแจ้งหนี้ → ไปที่ใบเสร็จรับเงิน → ไปที่หนังสือส่งมอบ →

🗑️ ออกจากระบบและล้างแคชในเครื่องนี้

สำหรับคอมพิวเตอร์สาธารณะ/เครื่องร่วม — กดปุ่มนี้เพื่อลบ token การเข้าสู่ระบบและแคชในเบราว์เซอร์นี้ เอกสารบน Cloud จะไม่ถูกลบ (เข้าสู่ระบบใหม่ก็ยังเห็นข้อมูลเดิม)

เอกสารทั้งหมดพร้อมพิมพ์ออก A4 · ใช้งานฟรี
